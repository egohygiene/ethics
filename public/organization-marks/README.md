# Organization marks

The Ethics resources gallery uses locally hosted images and does not fetch external brand assets from visitors' browsers.

- `huggingface.svg`: Hugging Face mark from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/huggingface.svg).

Other organization tiles use original typographic placeholders rather than reproductions of official trademarks. Replace them with locally hosted, source-verified official marks only when an appropriate use or redistribution basis is documented. Avoid loading logos or favicons from third-party hosts at runtime.
