# Contributing

Bring a better source, a clearer distinction, a useful repair, or a reproducible experiment. Criticism of the author's assumptions is welcome.

For evidence changes, identify the record, primary source URL and locator, reporting period, publication date, unit, denominator, geography, scope, method, uncertainty, and access/reuse terms. Distinguish AI-specific observations from total data-center statistics, estimates from projections, and measured outcomes from hypotheses.

Edit canonical records under `data/reviewed/`, then run `npm run check`. Inspect the generated JSON and manifest diff. Never hand-edit public materialized files, infer missing values, fabricate human review, or convert research metadata into an unsupported conclusion. Open a PR; source updates require review before publication.

For code, use Node.js 24, pinned dependencies, small modules and native APIs. Run the production browser checks for interface changes. Support keyboard controls, visible focus, dark/light themes, reduced motion, exact-value alternatives, and narrow screens. Avoid trackers, remote fonts, unnecessary runtime services, moral rankings, and personal attacks.

See [AGENTS.md](AGENTS.md), [METHODOLOGY.md](METHODOLOGY.md), and [DATA_SOURCES.md](DATA_SOURCES.md) for the governing contracts. Material disputes should remain visible until addressed with evidence; disagreement is not proof of bad motives.
